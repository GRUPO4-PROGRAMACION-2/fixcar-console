# Taller de consola

Proyecto base de consola con Java 21. No incluye todavía las funciones del taller.

## Requisitos

- JDK 21
- Maven 3.9 o posterior

## Compilar

```powershell
mvn clean package
```

## Ejecutar

```powershell
java -cp target/classes taller.Main
```

Las tareas de desarrollo están en [`docs/tareas/`](docs/tareas/README.md).
